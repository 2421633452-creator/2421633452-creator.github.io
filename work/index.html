04案例 · WORK

每个案例都按
同一组字段呈现。

案例的价值不在于展示客户名单，而在于说清「遇到了什么问题、做了什么、结果如何」。没有结果数据的案例，我们不会编一个。

01

案例字段标准

所有案例必须包含以下字段，缺一不可（结果字段除外，见下）。

  • 客户 / Client：客户名称；不能公开时写「某 + 市场 + 品类 + 品牌」
  • 行业 / Industry：对应行业清单中的一项
  • 目标市场 / Market：具体国家 / 地区
  • 挑战 / Challenge：客户当时的问题，1–2 句。
  • 解决方案 / Solution：麦炽做了什么，1–2 句。
  • 执行 / Execution：具体交付物，可含数量。
  • 结果 / Result：必须有数据来源；无来源则留空。
02

结果数据的处理规则

结果字段是唯一允许留空的字段。三种处理路径按优先级排列：

  • 客户授权披露具体数据 → 使用具体数字，并注明统计周期。
  • 客户不授权 → 使用可验证的过程指标：覆盖市场数、上线素材量、投放平台数、合作红人数、项目周期。
  • 两者都不可 → 结果字段留空，页面不显示该字段。不编造。
